#  Subscription Retention Analysis using SQL

## 📌 Project Overview

This project is a **Subscription Retention Analytics System** developed using **MySQL**.  
It simulates a real-world subscription-based business model similar to OTT platforms like Netflix, Spotify, and JioCinema.

The project focuses on:

- Customer churn analysis
- Subscription lifecycle tracking
- Revenue and payment analytics
- Viewing engagement analysis
- Customer retention insights using SQL

The main objective of this project is to analyze customer behavior and identify factors affecting subscription retention.

# 🗂 Database Schema

The project contains the following tables:

| Table Name | Description |
|------------|-------------|
| customers | Stores customer profile information |
| subscriptions | Stores subscription lifecycle details |
| payments | Stores transaction and payment records |
| viewing_activity | Stores customer engagement data |
